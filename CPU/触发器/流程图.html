玩法：拨 D=1 → Q 不动 → 按 CLK → Q 才变 1。CLK=1 期间再拨 D，Q 也不会变 —— 边沿触发的意义。

NOR 和 NAND 刚好"对偶"：串 ↔ 并、PMOS ↔ NMOS 互换。对比着拨一遍就懂。
  • 上拉网络（PMOS）负责输出 1，下拉网络（NMOS）负责输出 0，两者互斥、静态零功耗
  • NAND = PMOS 并联 + NMOS 串联；NOR 恰好对偶
  • 与门 = NAND+NOT、或门 = NOR+NOT：所有逻辑都能由这几个门搭出

L4

MOSFET 场效应晶体管 —— 电压控制的开关

栅 G / 漏 D / 源 S · 阈值电压 VTH · 左：剖面结构，右：接成开关电路
栅极电压 V_G0 V（低）
拨高 V_G：剖面图里绿色沟道"长"出来，电子从源流到漏（金点动画），右边灯亮 —— 一个晶体管就是一个受电压控制的开关。
  • NMOS：V_G 高于阈值 → 导通；PMOS 对偶：V_G 低才导通（符号加气泡 = 取反）
  • 栅极隔着氧化层只靠电场控制沟道，几乎不耗电流 → CMOS 静态功耗≈0
  • PMOS 放上、NMOS 放下共用栅极 = 上一层的 CMOS 门
拆开一层 ↓ 源、漏、沟道到底是什么材料
L5

半导体掺杂 Silicon Doping —— 一切的最底层

本征（纯）硅 / N 型（掺磷）/ P 型（掺硼）
纯硅几乎不导电。掺一个磷原子 → 多出一个到处乱跑的自由电子；掺一个硼原子 → 留下一个会"移动"的空穴。
  • N 型（负）：多子是电子 → 做 NMOS 的源/漏；P 型（正）：多子是空穴 → 做 PMOS 的源/漏
  • NMOS = P 衬底 + N⁺ 源漏；PMOS 全反过来 —— 上层晶体管的材料来源
  • 现代 CPU：指甲盖大的硅片上，数百亿个这样的开关协同工作
寄存器 ← 触发器 ← 逻辑门 ← MOSFET ← 掺杂硅：五层通用原理，拨一遍开关就懂了。
